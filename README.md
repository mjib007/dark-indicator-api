## 👋 關於這個專案

> 「**這套系統最早不是為了投資人寫的——它是為了抓證券犯罪而生。**」😀

時間回到 2016 年，我在調查局想推動一個構想：**證券犯罪預測系統**。

2012年，當時正值大數據崛起，證券數據日趨完善。當時調查局發掘證券犯罪案件主要是依賴看報找線索、等待主管機關移送，或當事人檢舉的被動模式，而我已開始構思「證券犯罪預警系統」的雛型，透過分析財報的「特徵值」，在炒股、掏空、財報不實**真正爆發之前**，就能從數據中嗅出味道，即使無法成為直接證據，但機先預防事情的發生，可以保護更多的投資人。

然而，雖然我建立龐大的證券犯罪判決資料庫，搜尋相關文獻，到處遍訪高手，建立出二十餘個判斷規則，這個想法始終未獲各單位首長支持，一來**沒人懂**，二來只要是**改變就會遇上阻力**，在當時沒能順利落地，成為一個有意義的證券犯罪預測系統，非常可惜。

但我捨不得讓這套累積多年的辨識邏輯就這樣躺在抽屜裡。

於是我做了一個決定：**大材小用，給一般投資人用**，一般投資人看的是正向指標，例如營收、毛利率、營利率、稅前淨利、EPS等數據，而本系統則是著眼於**負項指標**切入。把「抓壞人」的特徵值，變成「**避開地雷股**」的雷達。讓使用者從調查官的專業視角，翻譯成投資人聽得懂的語言。

如今**AI時代來臨，技術不再是障礙**。我已建立完整的分析平台，雖然不再用於犯罪預防，而是專注於個人投資決策輔助，我稱之為「暗黑股市指標」（原名「屠龍寶刀指標」）。回首調查局現況，辦案模式似乎依舊，令人感慨。

## 🎯 什麼是「暗黑股市指標」？

如果說現金流量表是健康檢查，
那暗黑指標就是**犯罪鑑識**——專門找出財報背後**不對勁的氣味**。

它不是傳統價值投資指標（本益比、殖利率那種），
而是基於我多年觀察證券犯罪案件，**歸納出的「壞股票共同特徵」**。

### 五大資料區塊，39 項指標全自動掃描

| 區塊 | 重點指標 | 你能看出什麼 |
|------|---------|-------------|
| 📊 **基本資料** | 股票名稱、產業別 | 屬於哪種產業，套用對的標準 |
| 💰 **損益表** | 營收 YoY、EPS YoY、毛利率、業外比重 | **獲利是不是真的賺，還是業外撐場** |
| 💸 **現金流量表** | A 營業/B 投資/C 融資/E 期末餘額 | **公司現金到底夠不夠用** |
| 🏦 **資產負債表** | 應收帳款 YoY、存貨 YoY、負債比、流動比 | **應收暴增是不是出貨灌帳？** |
| 📈 **交易資訊** | 融資使用率、當沖率、本益比、週轉率 | **籌碼面有沒有異常** |

## 🌟 v2.0 新功能：營運品質雙重過濾

單看營收成長很容易被誤導 —— 因為公司可以靠**讓客戶賒帳**或**狂塞貨給通路**衝出漂亮數字。
為了穿透這層迷霧，系統會自動執行兩道檢驗：

| 檢驗 | 規則 | 觸發警示時的白話意義 |
|------|------|-------------------|
| **應收帳款檢驗（回款能力）** | 應收帳款 YoY < 營收 YoY | 營收增加但收不到錢 — 像店家為衝業績讓客人賒帳 |
| **存貨檢驗（銷售效率）** | 存貨 YoY < 營收 YoY | 進貨速度比賣出速度快 — 倉庫越堆越滿，未來恐降價清庫存 |

> 💡 **設計理念**：規則由 Python 精準計算（避免 AI 數字判斷出錯），
> AI 只負責用生活案例做白話解讀（發揮語言能力強項）。

### 範例輸出

```json
"營運品質分析": {
"1.應收帳款檢驗(回款能力)": {
"數值": "3.1%",
"結果": "通過 ✅",
"說明": "應收帳款增速低於營收"
},
"2.存貨檢驗(銷售效率)": {
"數值": "0.1%",
"結果": "通過 ✅",
"說明": "存貨增速低於營收"
},
"分析基準(營收YoY)": "20.5%"
}
```

## 💀 五大致命組合：壞股票的指紋

這是這套系統的**靈魂**。
單一指標異常不可怕，**多個指標同時亮紅燈**才是真正的死亡訊號。

我從多年案例歸納出五種「**致命組合**」——
只要符合任何一組，這檔股票就值得**高度警戒**。

### 💀 致命組合 1：債務 + 現金流危機

> 「公司燒錢比賺錢快，還欠一屁股債。」

**特徵值**：營業現金流 < 0 + 負債比 > 50% + 流動比 < 1.0

🔴 **白話**：核心業務不賺現金、財務槓桿過高、短期還不出錢。
這是教科書級的破產前兆組合，LeEco 倒下前就是這個狀態。

---

### 💀 致命組合 2：融資賣壓崩盤

> 「散戶大量借錢買股，籌碼隨時鬆動。」

**特徵值**：融資使用率 > 60% + 融資賣壓倍數 > 0.3 + 當沖率 > 30%

🔴 **白話**：股票被融資資金堆高、當沖客滿天飛、隨時可能斷頭崩跌。
這種股票就像**疊到一半的骨牌**，一推就倒。

---

### 💀 致命組合 3：獲利品質惡化

> 「營收漂亮，但賺的不是本業的錢。」

**特徵值**：營收成長 > 10% + EPS 衰退 > -10% + 業外比重 > 50%

🔴 **白話**：營收看似成長，EPS 卻衰退，而且超過一半的利潤來自業外（賣土地、處分資產、匯兌收益）。
**這代表本業正在惡化，只是被一次性收益遮住了。**

> 🔄 **v2.0 升級**：新增的「營運品質雙重過濾」是這個組合的**先行指標** ——
> 在 EPS 還沒衰退之前，就能從應收帳款、存貨異常成長嗅到問題。

---

### 💀 致命組合 4：內部人逃命

> 「最了解公司的人，正在悄悄賣股。」

**特徵值**：董監持股下降 + 質押率 > 30% + 大股東異動 > 3 次

🔴 **白話**：董監事減持、把股票拿去質押借錢、十大股東頻繁進出。
**內部人比誰都清楚公司狀況**——他們跑，你還留嗎？

> ⚠️ 此組合需要籌碼面資料（公開資訊觀測站），FinMind 目前無法提供，系統會標記為「需手動補資料」。

---

### 💀 致命組合 5：矛盾護盤

> 「一邊買回庫藏股護盤，一邊發可轉債籌錢——這不矛盾嗎？」

**特徵值**：庫藏股 + 可轉債同時發生

🔴 **白話**：庫藏股是「我有閒錢買回自家股票」，可轉債是「我缺錢請人借我」。
**兩件事同時發生，通常代表表面護盤、實則挖洞。**

> ⚠️ 此組合需要重大訊息資料，FinMind 目前無法提供，系統會標記為「需手動補資料」。

## 🔍 實戰案例:精成科 6191 的暗黑訊號

這是我課堂上實際講過的真實案例。

### 第 1 步:暗黑指標亮警示

輸入 6191，系統立刻發現**自由現金流（A+B）是負值**——
意思是「**營業活動賺進來的錢，不夠拿去做投資**」。

換成白話：**這家公司本業賺的錢，不夠花在自己身上。**

### 第 2 步:到 GoodInfo 比對

進到 GoodInfo 現金流量表簡表，確認這個負值不是我系統算錯。

### 第 3 步:打開現金流量表「完整版」

在詳細的子項目裡，我找到關鍵的那一行：
**「按攤銷後成本衡量之金融資產（增加）減少」**

### 第 4 步:破案

原來這家公司**拿錢去買公債了**。

這代表什麼？
- ✅ **不是壞事**：資金停泊，賺利息
- ⚠️ **但要追問**：為什麼本業不擴張？是產業不景氣？還是經營層保守？
- 🔴 **更要警惕**：如果公司同時又在借錢，那就是「**借錢買公債**」的詭異組合

> 💡 **這就是暗黑指標的價值**——它不直接告訴你答案，而是**指出該追問的方向**。

## 🚀 核心功能

### 🤖 全自動 39 項指標掃描
串接 [FinMind](https://github.com/FinMind/FinMind) API，自動抓取台股 2 年內的：
- 基本資料、損益表、月營收
- 現金流量表、資產負債表
- 融資融券、日股價、當沖、本益比

### 📐 自動 YoY 比對
不只給你最新一季數字，還會**自動找去年同期**做年增率比對。
這是 Excel 最痛苦的工作，系統 1 秒搞定。

### 🚨 五大致命組合自動掃描
不需要你自己對照，系統會逐一檢查每個組合的觸發條件。

### ⚠️ 警示標準對照
| 指標 | 警示門檻 |
|------|---------|
| 營收成長率 | < 0% |
| EPS 年增率 | < 0% |
| 營業利益率 | < 5% |
| 毛利率 | < 10% |
| 業外損益比重 | > 50% |
| 負債比率 | > 50% |
| 流動比率 | < 1.0 |
| 速動比率 | < 0.8 |
| 融資使用率 | > 60% |
| 本益比 | < 0 或 > 50 |

### 🎯 透明標註資料缺口
不騙你「全自動」——FinMind 拿不到的籌碼面資料（董監持股、質押率、大股東異動、庫藏股、可轉債），系統會**明確標記「需公開資訊觀測站」**，提醒你手動補。

↓
前端介面(HTML)

| 欄位 | 說明 |

## ❓ 常見問題（FAQ）

### Q1：為什麼有些指標顯示「FinMind 無資料」？

FinMind 是免費資料源，**不是萬能**。
籌碼面資料（董監持股、質押率、大股東異動）和特殊事件（庫藏股、可轉債）需要從**公開資訊觀測站**或**重大訊息公告**取得，FinMind API 沒有提供。

我選擇在系統裡**誠實標記**這些缺口，而不是假裝它有。
若你需要完整資料，可以手動補上這幾項。

### Q2：致命組合 4 和 5 為什麼總是無法觸發？

因為這兩組需要的資料（董監持股、質押率、庫藏股、可轉債），正好都是 FinMind 拿不到的。
系統會在回應裡標記「**需手動確認**」，提醒你別誤判為「沒問題」。

### Q3：啟動時出現 `ModuleNotFoundError`？

代表你跳過了「安裝套件」這一步。請先執行：

pip install -r requirements.txt

### Q4：這套系統可以保證抓到所有地雷股嗎？

**不能，也不應該宣稱能。**
暗黑指標是「**異常偵測**」，不是「**未來預測**」。
它告訴你「**這家公司有幾個指標在尖叫**」，但不保證股票一定會跌。
最終決策請結合產業知識、總體經濟、和你自己的風險承受度。
